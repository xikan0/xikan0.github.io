# 指针

## 指针的概念

指针是一种特殊的数据类型，用于表示内存地址，（存放另一个变量的地址的变量）

**内存的基本单位是字节**，每个字节由8位二进制位（bit）组成，内存是连续的编址空间，每一个字节有唯一的地址标识

1. 指针是无符号整数
2. 指针的运算不同于整型
3. 变量定义后，该变量的地址是**指针常量**
4. 完整的指针类型包括基类型

#### 指针与整数的区别：

从形式上看，地址（指针）是整数，但**指针是无符号整数**，其表示范围由系统的寻址空间所确定，而不一定与整形相同，操作上，指针运算不同于整形，例如**指针能解引用（\*）运算**

常使用 `%p` 格式符来输出**十六进制形式的地址**

**指针的基类型：**指定存储对象的类型

> 例：**`int *p;` 则称int为指针p的基类型，或指针p所指向的变量的类型**

**指针的声明形式：**

```c
int *p;
//和第一种没区别
int* p1;
//p3是一个指针，p4只是一个int型变量，p6是指针
int* p3,p4;
int* p5,*p6;

//让指针指向一个变量（给指针赋值）
int *p=&i;
//或者
int *p;p=&i;

```

#### &的实质（扩展，了解）

使用&时，返回的是一个“指向T的指针”类型的常量，即**指针常量**

当要给指针赋值，赋一个绝对地址时，通常先将地址写成**整形常量**的形式，然后强转成相应的类型，如：`int*、double*`（因为C语言中没有方法去表示指针常量）

```c
//给指针赋绝对(确定的)地址
int *p=(int*)0x12345678;
```

但一般来说：**除了0之外，整数不能赋给指针变量**

#### \* 解引用操作符

![](https://cdn.jsdelivr.net/gh/xikan0/ImgHosting@main/PIC/P2.jpg)

\*在定义时用来说明一个变量是指针，当使用指针时，\*p表示的是**p所指向的对象（即i）**（对于一个已定义的指针使用 \* 操作符，将访问这个指针所指向的对象）

```c
#include <stdio.h>
int main(){
    int i;
    int *p;
    i = 2;
    p = &i;			/*将i的地址赋给p，即使p指向i*/
    printf("%d",i);		/*输出i的值*/
    printf("%d",*p);	/*输出p所指向的存储单元的值，即i的值*/
    return 0;
}
```



#### 指针变量的初始化

一个指针变量未被初始化时，指向的位置不确定，被称为**野指针**

**空指针常量：**一个具有0值的整形常量表达式，或者此表达式被强转为`void*`类型

例：将 0、 0L、 '\0'、 2-2、 0*5、 (void\*)0 赋给任意类型的一个指针，该指针就成为了空指针

由系统保证**空指针不指向任何对象或函数**

C 还定义了一个宏 **<font color=red>NULL</font>**，用来表示空指针常量

```c
#define NULL ((void*)0)
```

对指针进行初始化的几种方式：

```c
//1.采用NULL或空指针常量
int *p = NULL;
char *p = 2-2;
float *p = 0;
//2.取一个对象的地址，然后赋给一个指针
int i = 3; int *p = &i;
//3.将一个T类型数组的名字赋给一个相同类型的指针
char ary[100];
char *cp = ary;
//4.将一个指针的地址赋给一个指针
int i = 3;
int *p = &i;
int **pp=&p;	
/*其中，*p=i,**pp=i,**pp进行了两次解引用，第一次指向了p,而第二次则是指向了p所指向的i，当只有*pp时，指向的只有存储p这个指针的地址*/

//5.将一个字符串常量赋给一个字符指针
char *cp = "abcdefg";
//6.将一个指针常量赋给一个指针
long *p=(long*)0xffffff0;
```

在C语言中，将一个字符串常量赋给一个字符指针时，字符指针中存储的是**字符串常量的首地址**。字符串常量在内存中是连续存储的，并且以字符'\0'结尾，字符指针指向字符串的起始位置

对指针进行初始化或赋值的实质是**将一个地址或同类型（或兼容的类型）的指针赋给它**，而不管这个地址是怎么取得的

对于一个不确定要指向何种类型的指针，定义之后最好初始化为**NULL**



#### void\* 型指针

表示定义了一个指针，但不指定它指向何种类型的数据，**有基类型，基类型是 `void`**

void\* 型指针作为一种通用的指针，<font color=red>**可以和其他任何类型的指针（函数指针除外）相互转化而不需要强转**</font>，**但无法进行解引用或下标操作**

<font color=red>**不能进行解引用的：野指针、空指针、void*型指针**</font>

#### 多级指针（指向指针的指针）

常用的是二级指针

```c
int i = 5000;
int *pi = &i;
int **ppi=&pi;
```

#### 常量指针与指针常量（了解）

常量指针：指针本身的值不可被改变，`int *const a;`

指针常量：一个指针类型的常量，`(int*)0x123456ff`

指向const的指针：一个指针它所指向的是一个const对象，`const int *p`，表明p是一个指向const int 型变量的指针，p自身的值可以被改变，但不能通过对p解引用来改变所指的对象的值

> 注意：*const int* 表示“	指向一个具有*const*限定符的*int*类型的指针	”，即*const*所修饰的是指针所指向的类型，而非指针

## 指针与函数

函数的局限性：

1. 函数调用只能是单向“传值”的方式，被调用的函数无法访问主调函数中定义的对象
2. 函数只能返回唯一的函数值
3. 只能向函数传值，不能“传操作”，即参数不能是函数

#### 指针作函数参数

1. 变量名作实参时，传递的是变量的值，称为**按值调用**
2. 变量的地址作实参，传递的是变量的地址，称为**按地址调用**

> <font color=red>易错点：</font>
>
> <font color=red>1. C语言只有唯一的传参数方式，即单向传值</font>
>
> 传地址也是单向传值，更改形参的值（地址），主调函数里的实参的值（地址）没关系，不过他俩解引用都指向同一个地址，所以可以用来更改同一个变量
>
> <font color=red>2. 函数只能有一个返回值，但可通过指针来获取函数的多个计算结果</font>



#### 函数指针与指针函数

##### 指针函数：

本质是一个函数，该函数的返回值是一个指针

声明格式为：`类型标识符 *函数名(参数表)`

> 解析类型声明需要遵循“从右往左”的顺序，先解释代表函数的（参数表），即它是一个函数，再看函数的原型为“类型 \*”

```c
int *fun(int x,int y);
int * fun(int x,int y)；
int* fun(int x,int y);	//该函数返回的是一个int型的指针，是一个地址
```

可以将返回值定义为 `void*` 型，接收时需要<font color=red>**强转**</font>成自己需要接收的类型

##### 函数指针：（指针常量）

本质是一个指针变量，该指针指向这个函数（就是指向函数的指针）

声明格式：`int (*fun)(int x,int y);`

函数指针需要把一个函数的地址赋给它：（这样就可以解引用这个指针来调用这个函数）

```c
fun = &Function;
fun = Function;
```

&地址运算符不是必须的，因为一个**函数标识符就表示了它的地址**，如果是函数调用，还必须包含一个圆括号括起来的参数表

调用函数指针：

```c
x = (*fun)();
x = fun();	//这两个是一样的
```



## 指针的算数运算

#### 指针来访问数组中的元素

```c
char ary[100]={'a','b','c','d','e'};
char *cp =ary;		//*cp现在指向了数组的第1个元素
char *cp =&ary[3]	//*cp现在指向了数组的第4个元素
/*因为数组名代表该数组的第一个元素地址（元素的起始地址），所以赋变量时不用&，但其他位置的元素就需要了*/
```

注意：

1. 在C语言中，访问数组元素本质就是**间接访问**
2. **访问数组元素p[i]，p不一定是数组名，p是指向该数组内任意一个元素的指针即可**，但那样下标的范围就不是0 ~ n-1 了，而是p所指向的那个元素为原点0，左边下标是负数，右边下标是正数

#### 指针+整数 或指针-整数

指针 + 整数 = 另一个指针

如：上述的 cp + 1，则产生的指针指向数组中的下一个字符，<font color=red>`a[i]==*(a+i)`</font>

当指针相加减时，所做的就是指针加上或减去步长乘以那个整数的积，步长就是指针所指向的类型的大小（即指针移动一个位置时要跳过几个字节）

```c
int ia[100]={1,2,3,4,5};
int *ip=ia;
ip+=3;
/*其中，ip加上3实际进行的操作是ip+4*3，因为ip指向的元素类型为int*/
ip++;

/*自增、自减后再解引用*/
++*p;
*++p;
```

> 注意：
>
> 1. 原来的指针和计算后的新指针都需要指向同一个数组的元素、或指向数组数组范围的下一位置时才是合法的
> 2. 自增、自减运算符和\*取地址运算符、&的优先级相同，且都是按照自右向左方式结合



#### 指针 - 指针

<font color =red>注意：</font>**C标准里，没有定义两个指针相加的运算**，所以会报错

**指针的减法运算是有条件的：**当两个指针指向同一数组、或有一个指针指向该数组末端的下一位置时，两个指针可做减法运算

```c
int ia[100]={0,1,2,3,4,5};
int *ip = ia;
int 8ig = ia+3;
ptrdiff_t n = ig-ip;	/*ptrdiff_t是一个标准库类型，是一个无符号整数，可为负数*/
```

> 1. 两指针相减，得到的是两指针所指向元素之间的距离，也就是他们相隔几个数组元素，与步长没关系
> 2. 指针可以加减0，指针保持不变，空指针也可以加减0，
> 3. 两个空指针相减，结果也是0

#### 指针的关系运算

两指针可进行关系判断：==、!=、<=、>=

判断大小是根据在数组中的相对位置来判断的，如：q[2] <= q[4]

## 指针与数组

### 数组名

数组名代表该数组的第一个元素地址（元素的起始地址），<font color=red>**数组名是一个常量指针（常指针），自身的值不能改变**</font>

在对数组名实施*&*操作时，返回的是一个指向数组的指针，而非具有某个指针常量值的指针

数组和指针的差别：

- 声明数组时，同时分配了用于容纳数组元素的空间
- 声明指针时，只分配了用于容纳指针本身的空间



#### 通过数组名引用元素

```c
int last = ia[99];
int last = *(ia+99);
*&ai[99] 	/*先取ai[99]的地址，再解引用*/
```

解释：

1. ia是数组名，也就是一个指向首个元素的常量指针：ai[0]
2. 指针可以加整数，返回一个新的指针，指向该数组内的元素的地址
3. `*(ai+99)`也就是从 `ai[0]` 开始向后99位，也就是 `ai[99]`
4. 数组名是常指针，不能对它的值进行修改。*ia + 99*是可以的，但*ia++*是不行的，它的意思是*ia = ia +1;*修改了*ia*的值



#### 函数形参中的数组

一、声明函数形参，<font color=red>数组会被改写成指向数组第一个元素的指针</font>

```c
void array(int *ia){}		
void array(int ia[]){}		//ia[] 被转换成 *ia
void array(int ia[100]){}	//ia[100] 被转换成 *ia
```

当**数组名**作为函数形参时，已经被转换成了一般的指针（不是常指针了），因此，这个形参数组名的值可以被改变了。此时，不能通过sizeof运算符获取数组的长度，不能判断数组的长度时，可能会产生数组越界访问。因此传递数组名时，需要一起传递数组的长度。

```c
void array(int ia[100]){
    ia++;	/*这个是合法的*/
    int id[100]={1,2,3,4,5};
    id++;	/*这个是不合法的*/
}
```

<font color=red>C语言中，所有非数组形式的实参（包括指针）均以**值传递**的形式调用</font>（形参值的变换不影响实参）

例如：主函数传了一个指针，给一个函数的形参，**形参拿到的指针是原指针的副本，无法影响实参，但都指向一个地址，可以影响地址里的值**

---

二、用 `sizeof(形参数组名)`，来获得数组的大小时，只能得到一个指针的大小（因为形参数组名只是一个指针了）

- **<font color=red>32位系统中，指针大小通常为4字节</font>**
- **64位系统中，指针大小通常为8字节**



### 指向数组的指针(二维数组)

指向数组的指针主要用来对二维数组进行操作

#### 用指针定义二维数组

**数组指针：**`标识符类型 (*标识符)[整形常量]`

<font color=red>二维数组名的类型为 **数组指针** 类型</font>

```c
int m[50][100];
int (*p)[100]=m;
```

其中，`*p` 指向的是数组的第一个元素，而后面的 `[100]` 下标，则表示这一个元素里又有个长度为100的整形数组，`(*p)[100]` 就代表每个元素都是一个 `int[100]` 型的数组，通过对 p 的算数运算可以使它指向 m 数组中的任意一个元素，而不需要指导 m 是一个多长的数组， 但一定要知道 m 中每个数组元素的长度

所以这个二维数组的步长：p + n，也就是 `n*100*sizeof(int)` 个字节，相当于跳过矩阵中的 n 行，每行都有 100 个 int 型元素

数组越界的问题：

**对指针的算术运算可以使它指向数组中的任何一个元素包括超出数组范围的第一个元素**，这个超出范围的第一个元素实际上是不存在的，这个“元素”的地址在数组所占的内存之后，它是数组的第一个出界点

这个地址可以赋给指向数组元素的指针，但ANSI C仅允许它进行赋值或比较运算，不能对保存这个地址的指针进行解引用或下标运算。

```c
#include <stdio.h>
int mian(){
    int m[2][4] = {
        {1,2,3,4},
        {5,6,7,8}
    };
    int (*p)[4] = m;
    
    int i = p[1][2];	//可以通过p[i][j]的形式访问数组内的元素
    printf("%p",p);		//输出0xffe00
    printf("%p",p+1);	//输出0xffe10, 跨了一个数组元素，这个数组的大小：4*4=16，所以十六进制里进一
    return 0;
}
```

在表达式中一维数组名会转换为指向数组第一个元素的指针，二维数组也是一样的，所以也会被转换为指向第一个元素的指针，它的第一个元素是一个数组，所以最终的结果就是**二维数组名被转换成指向数组的指针**

关于二维数组的数组名：

`int (*p)[100] = m` 中，对于 `m[n]` ，是 m 数组的第 n+1个元素的名字，也就是数组名

所以可以有  `p=&m[n]` ，其中p指向了一个数组元素，也就是矩阵中的某一行

```c
int *column_p = m[n];
```

当对 m[n] 进行 sizeof 操作时，结果是 100\*sizeof(int) ；而 sizeof(m) 结果是50\*100\*sizeof(int)

### 指针数组、数组指针

明确运算符优先顺序：`() > [] > *`

#### 指针数组

例子：`int *p[100]`

根据优先级，先看`[]`，则 p 是一个数组，该数组是一个 `int *` 型，因此数组的元素是指针类型，共 100 个元素。称为“指针的数组”，即指针数组

#### 数组指针

<font color=red>行指针</font>是一个**指向一维数组的指针**，它专门用来操作二维数组中的"整行"数据

例子：`int (*p)[100]`

根据优先级，先看括号内，可知 p 是一个指针，这个指针指向一个一维数组，数组长度为 100 。称为“指向数组的指针”，即数组指针

## 字符串与指针（了解）

`char *cp = "abcdefg";`中"abcdefg"会被转换为一个没有名字的字符数组，这个数组被 abcdefg 和一个空字符 '/0' 初始化，并且会得到一个指针，它的值为第一个字符的地址

```c
	printf("%c\n",*"abcdefg");			//字符串常量的值是一个指针常量，指向的是字符串的第一个字符，输出a
	printf("%c\n", *("abcdefg"+ 1));	//对这个指针进行算术运算则其指向下一个字符，再对它解引用输出b
	printf("%c\n","abcdefg"[5]);		//既然"abcdefg"是一个指针，那么"abcdefg"[5]就可以写成*("abcdefg" + 5)，输出f
	printf("%s",cp);	//直接通过该指针访问整个字符串
```

可以快速初始化字符数组：`char ca[]="abcdefg";`

两个方法的对比：

```c
char ca[]="abcdefg";	//初始化一个字符数组的元素
char *cp ="abcdefg";	//一个字符串常量
```

用来初始化字符数组的字符串常量，编译器会在栈中为字符数组分配空间，然后把字符串中的所有字符复制到数组中

用来初始化字符指针的字符串常量会被编译器安排到只读数据存储区，但也是按字符数组的形式来存储的，可以**通过一个字符指针读取字符串常量但不能修改它**，否则会发生运行时错误

<font color=red>**不是所有的字符串常量都放在不同的地址**</font>

```c
char str1[] = "abc";
char str2[] = "abc";
char *str3="abc";
char *str4="abc";

printf("%d\n",str1==str2);	//输出0
printf("%d\n",str3==str4);	//输出1
```

str1 和 str2 在栈中各自有不同的空间，而 str3 和 str4 是两个字符指针，分别被初始化为相同字符的字符串常量，二者指向相同的区域

#### 指针的值传递（了解）

```c
#include <stdio.h>
void pointer_plus(char**p){
    *p += 3;
}
int main( ){
    char*a = "abcd";
    pointer_plus(&a);
    printf("%c\n", *a);
    return0;
}
```

1. a是一个字符指针，拿到的是字符串常量的第一个字符的地址，**（这个地址是常量，但a不是）**
2. 将 a 的存储地址给到函数pointer_plus，将 a 所指向的地址向后推了3位=在主函数里`a+=3;`
3. 所以可通过传递指针的指针（复制的），来改变原指针所指向的位置（被复制的改了）

## 动态内存分配

定义变量、数组，都是为存储对象**静态分配内存**

#### 动态分配和静态分配的区别：

1. **分配时机：**

   静态分配在编译期就确定内存的大小和位置；动态则是在程序运行时根据需要来分配或释放内存

2. **管理方式：**

   静态分配由编译器自动管理，程序员无法干预；动态则需要手动管理

---

#### malloc 和 free

C标准库里用这两个函数来动态分配内存和释放、共同维护一个内存池

**一、`malloc`函数**

向内存申请一块连续可用的空间，并返回指向块开头的指针

`void *malloc(size_t size)`

函数动态分配size字节的内存块，类型`size_t`是用来表示内存大小的无符号整型，若内存分配失败，则返回NULL；若分配成功，则返回内存块的起始地址（基地址）

```c
int *p;
p = (int *)malloc(sizeof(int)*10);
if(p!=NULL)
    for(int i=0;i<10;i++)
        p[i] = 0;
```

> 注意：
>
> 1. malloc的返回值是`void*`型，强转是不必要的，推荐加上
> 2. 分配的内存大小可以用 `sizeof（）` 乘所需要的类型的个数

**二、free函数**

<font color=red>**动态分配的内存不会自动释放，必须由程序员调用free函数释放**</font>

`void free(void *ptr)`

1. `free` 函数<font color=red>只能释放动态分配的内存块</font>
2. 如果 ptr 是零指针（空指针），则 free 函数不运行操作
3. 函数将释放 ptr 指向的内存块

#### calloc和realloc

**一、`calloc`函数**

`void* calloc (size_t num,size_t size);`

num 是要分配的元素个数，size 是每个元素的字节数，它会在内存中分配 num \* size 字节的连续空间

```c
int *p;
p = (int *)calloc(5,sizeof(int));
```

**二、`realloc`函数**

`void* realloc(void* ptr, size_t size);`

重新分配已经存在的内存的空间大小

ptr 表示要重新分配大小的指针，size 表示重新分配内存的大小，

- 分配成功返回一个指针，不成功返回NULL
- 重新分配的大于原来大小，原来的值会保留
- 如果小于原来大小，多于的会被释放掉
